## 🎯 Template Usage Guide

### For Advent of Code Work
1. **Starting new year**: Copy `stats_dashboard_template.md` → `advent_of_code/aoc20XX/Problem_Statements/summary_20XX.md`
2. **After solving each day**: Use `function_guide_template.md` for `days/dayXX_function_guide.md`
3. **Daily notes**: Use `daily_note_aoc_entry_template.md` section in zettelkasten daily notes

**Workflow**: See [POST_IMPLEMENTATION_PLAN.md](aoc_documentation/POST_IMPLEMENTATION_PLAN.md)

### For Project Euler Work
No specific templates yet - mathematical write-ups documented in project_euler repo.

### For Daily Learning
- **Daily notes**: Use Daily Notes Template for consistent structure
- **Weekly planning**: Use Weekly Notes Template for reflection and planning

## 📝 Template Maintenance

**When to update templates**:
- After completing a full AoC year (refine based on experience)
- When workflow improvements discovered
- When deprecating old patterns (mark clearly)

**Deprecation policy**:
- Mark deprecated templates with ⚠️ DEPRECATED at top
- Explain replacement approach
- Preserve original content in "Archived" section
- Update references from other docs
