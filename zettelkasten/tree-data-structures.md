---
title: Tree Data Structures
---

Tree data structures organize data hierarchically using parent–child relationships, enabling efficient search, aggregation, and structural queries. Interview problems often rely on binary trees, balanced search trees, and specialized trees like tries or segment trees.

This note provides a conceptual hub between high-level tree algorithms (traversals, LCA, balanced trees) and concrete Rust representations used in missions and AoC problems.
