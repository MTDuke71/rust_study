## 🔧 **Technical Insights**

### Cycle Detection Pattern for Billion-Scale Iteration

**Problem:** Simulating 1 billion iterations naively would take forever.

**Solution:** Detect when grid state repeats, then fast-forward:
```rust
// Track: state → first occurrence index
let mut seen: HashMap<String, usize> = HashMap::new();

for cycle in 0..1_000_000_000 {
    let state = serialize_grid(&grid);
    
    if let Some(&first_seen) = seen.get(&state) {
        // Found repeating pattern!
        let cycle_length = cycle - first_seen;
        
        // How many cycles remain after this one?
        let remaining = 1_000_000_000 - cycle;
        
        // Where in cycle will we end up?
        let final_offset = remaining % cycle_length;
        
        // Run just the remaining cycles
        for _ in 0..final_offset {
            spin_cycle(&mut grid);
        }
        
        return calculate_load(&grid);
    }
    
    seen.insert(state, cycle);
    spin_cycle(&mut grid);
}
```

**Key Insight:** Physical systems like this have finite states, so they **must** cycle eventually. Instead of simulating all billion iterations, find the cycle and use modulo arithmetic.

**Mathematical Foundation:** This is an application of the **Pigeonhole Principle** - with finite grid states, repetition is guaranteed.

### Directional Tilting Implementation

**Challenge:** Implement 4 different tilt directions efficiently.

**Solution:** Each direction processes grid differently:
- **North/South**: Process columns, track next available row
- **West/East**: Process rows, track next available column
- **Forward/Backward**: Scan direction depends on tilt direction

**Pattern:**
```rust
fn tilt_north(grid: &mut Grid<Tile>) {
    for col in 0..grid.width() {
        let mut next_free = 0; // Top of column
        for row in 0..grid.height() { // Scan downward
            match grid.get(Coord::new(col, row)) {
                RoundRock => {
                    move_to(col, next_free);
                    next_free += 1;
                }
                CubeRock => next_free = row + 1,
                Empty => {}
            }
        }
    }
}
```
