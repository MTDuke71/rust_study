## Day 17: Pyroclastic Flow

**Problem**: Simulate Tetris-like rocks falling in a 7-wide chamber, pushed by hot gas jets.

### Results
- **Part 1**: 3,109 (2,022 rocks) - 341µs
- **Part 2**: 1,541,449,275,365 (1 trillion rocks) - 400µs
- **Combined**: 734µs

### Algorithm

1. **Chamber as bitmask rows**: Each row is a `u8` (7 bits for 7 columns). Collision = bitwise AND, placement = bitwise OR. 1 byte per row instead of 7.

2. **Simulation loop**: For each rock — spawn at (x=2, y=height+3), alternate jet push + fall. Collision checks against walls, floor, and existing rocks.

3. **Cycle detection** (Part 2): Fingerprint state as `(rock_type, jet_index % len, top_30_rows)`. HashMap lookup finds when the same state repeats. Then extrapolate: skip `full_cycles × cycle_height`, simulate only the remainder. ~3,400 rocks simulated instead of 10^12.

### Key Insight: State Fingerprinting
The simulation is deterministic — same rock shape + same jet position + same tower top = identical future. Top-30 rows provides enough context to guarantee this. The cycle appears within a few thousand rocks for any real input.

## Patterns Worth Remembering

- **Bitmask row representation**: Fixed-width grids (7 columns) fit in `u8`. Collision/placement = single bitwise operation.
- **Cycle detection via state fingerprint**: For impossibly large iteration counts, snapshot deterministic state → HashMap → extrapolate with arithmetic.
- **Top-N profile**: Capture enough tower context to guarantee identical futures. 30 rows is conservative but reliable.
