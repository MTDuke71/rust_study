## 🔧 **Technical Insights**

### **Linear Algebra in Practice**

**Cramer's Rule** (2×2 systems):
- Perfect for small systems (one-off intersections)
- O(1) per solve after determinant calculation
- Numerical stability good for well-conditioned systems
- Day 24 Part 1: 44,850 uses, ~6.4 ns each

**Gaussian Elimination** (6×6 system):
- O(n³) complexity, but n=6 is tiny (216 operations)
- Partial pivoting essential for numerical stability
- Produces floating-point solution (requires integer refinement)
- Day 24 Part 2: ~25 µs solve time

**Local Search** for Integer Refinement:
- 3×3×3 neighborhood (27 candidates)
- Error function validates exact solution
- Robust to floating-point rounding errors
- Alternative to direct rounding (which may fail)

### **Cross-Product Variable Elimination**

**Problem**: Collision equations are nonlinear
```
rx + t·rvx = px + t·vx  (contains t·rvx product!)
```

**Solution**: Cross products eliminate time variables
```
(P₁ - P₂) × (V₁ - V₂) = (P₁ - P₂) × RV + RP × (V₁ - V₂)
```

**Result**: 
- Left side: Constant (known positions/velocities)
- Right side: Linear in (rx, ry, rz, rvx, rvy, rvz)
- Enables standard linear solvers!

**Why This Works**:
- Cross product distributes over addition
- Products of unknowns cancel algebraically
- Converts 6-unknown nonlinear → 6×6 linear system
- Uses only 4 hailstones (2 pairs × 3 equations each)

### **Parametric vs Cartesian Forms**

**Parametric Advantages**:
✅ Handles vertical lines naturally (vx = 0)
✅ Direction vector explicit
✅ Easy to restrict to rays (t ≥ 0) or segments (0 ≤ t ≤ 1)
✅ Natural time/motion interpretation
✅ Generate points trivially: plug in t values

**Cartesian Form** (ax + by = c):
- Vertical lines problematic (undefined slope)
- Direction implicit (perpendicular to normal)
- Ray/segment restrictions complex
- Better for static geometric relationships
