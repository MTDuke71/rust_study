## 🔧 **Technical Insights**

**ASCII Art Parsing**: Crate positions follow predictable pattern (1 + 4*n), enabling direct character indexing without complex parsing logic.

**Vec as Stack**: Natural LIFO operations with `push()`/`pop()` at end. Key insight: `split_off(index)` takes elements from index onward, preserving order - perfect for bulk stack moves.

**Part 1 vs Part 2 Difference**: 
- Moving [D, N, Z] one-at-a-time: pop D → push D, pop N → push N, pop Z → push Z = [Z, N, D] (reversed)
- Moving [D, N, Z] together: `split_off()` preserves as [D, N, Z], `extend()` maintains order

**Parse-Once Efficiency**: Cloning parsed data (~5µs overhead) cheaper than parsing twice (59.5µs), enabling efficient dual-part solving.
