## 🔧 **Technical Insights**

### Iterator Patterns Learned
- **`filter_map()` with `and_then()`**: Chain Option operations elegantly
  ```rust
  num_rows.iter()
      .filter_map(|row| row.get(i).and_then(|s| s.parse().ok()))
      .collect()
  ```
- **`char_indices().filter()`**: Find character positions by predicate
- **`(start..end).rev()`**: Iterate range in reverse (right-to-left columns)

### Copy vs Move
- Primitives like `usize`, `i64` are `Copy` - values are copied, not moved
- Range expressions `(start..end)` copy the values, so `start` and `end` remain usable

### String Parsing
- `chars().nth(col)` - O(n) access since strings are UTF-8 (can't index directly)
- `parse::<i64>()` - turbofish syntax tells parse() what type to convert to
