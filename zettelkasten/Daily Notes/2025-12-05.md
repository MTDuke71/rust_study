### AoC 2025 Day 5: Cafeteria ✅
- **Part 1**: Range containment - count ingredients in any fresh range (679)
- **Part 2**: Interval merging - count unique IDs across overlapping ranges (358155203664116)

**🚨 Learning Moment - HashSet Failure**:
- Initial idea: `HashSet` to collect all IDs from ranges
- Problem: Ranges were ENORMOUS (e.g., `169486974574545-170251643963353` = 765 billion values!)
- Lesson: **Always check input scale before choosing data structures!**

**✅ Interval Merging Algorithm**:
- Sort ranges by start → brings overlapping/adjacent ranges together
- Single pass: extend last range if overlap, else add new range
- Why sorting matters: O(n log n + n) vs O(n²) without sorting
- Mathematical counting: `sum(end - start + 1)` instead of enumeration

## 🔧 **Technical Insights**
- **Type States** work naturally with Rust's ownership - `Result<Success, Self>` returns ownership on failure
- **Loop + match** pattern handles unknown approval counts properly (vs `unwrap_err()` assumptions)
- **Enum wrappers** (`PostState`) allow storing "any state" when runtime flexibility needed
- Rust privacy: struct fields are private by default even with `pub struct`
- **Interval merging**: Sorting enables O(n) merge pass - only compare to LAST merged range
- **Input scale awareness**: Trillion-scale ranges require mathematical solutions, not enumeration
