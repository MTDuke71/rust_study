### AoC 2024 Day 15: Warehouse Woes ✅
**Problem**: Robot pushes boxes in warehouse following movement commands
- **Part 1**: Single-width boxes (`O`) forming 1D chains
- **Part 2**: Double-width boxes (`[]`) with 2D overlapping structures

**Bug Discovery & Fix**:
1. **Initial Bug** (commit a09d182): Only moved first/last box in chain
   - Example: `. O O O @>` became `O . . O @` (middle boxes vanished!)
   - Root cause: Only updated endpoints, ignored intermediate boxes

2. **Over-Engineered Fix** (commit 4bb6c60): Tracked all boxes, moved in reverse
   - Correct but unnecessarily complex
   - Updated every box position including middle boxes

3. **Elegant Solution** (final): Two-position update only
   - **Key insight**: Middle boxes don't change state (`O` → `O`)
   - Algorithm: Scan for empty → place box at empty → clear first position
   - **User contribution**: Recognized simpler approach through understanding

**Algorithm Patterns**:
- **Check-Then-Execute**: Validate entire chain before any modifications (atomic success/failure)
- **Part 2 Vertical Complexity**: HashSet deduplication prevents double-processing overlapping boxes
- **Distance-Based Ordering**: Move furthest boxes first to prevent overwriting unmoved boxes
- **Mission 6 Integration**: `Grid<Tile>` + `Coord` eliminate bounds errors and x/y confusion

**Python vs Rust Comparison**:
- **Python**: Unified functions with conditional dispatch (`if part == 1 or move in "<>"`)
- **Rust**: Separate functions (`try_move` vs `try_move_wide`) with type safety
- **Shared Insight**: Part 2 horizontal ≈ Part 1 (still 1D chains), only vertical needs 2D algorithm
- **Results**: Part 1 = 1,465,152, Part 2 = 1,511,259

## 🔧 **Technical Insights**

### AoC Day 15: Algorithm Optimization Journey
- **Simplification Through Understanding**: Deep problem analysis leads to simpler code
  - Don't just fix bugs—understand why they occurred
  - Initial "fix all boxes" → elegant "fix two endpoints" through insight
- **Atomic Operations**: Check-then-execute pattern eliminates need for rollback
  - Scan entire chain for empty space before modifying grid
  - Either entire operation succeeds or nothing changes (no partial states)
- **Deduplication is Critical**: HashSet prevents double-processing in graph-like structures
  - Part 2 overlapping boxes would move twice without visited tracking
  - Example: Box above two boxes gets added from both left and right checks
- **Python's Clever Unification**: Conditional dispatch hides three algorithms behind one interface
  - Part 1, Part 2 horizontal, Part 2 vertical—but unified function signatures
  - Key: Part 2 horizontal is algorithmically similar to Part 1 (1D chains)

### TCP and HTTP Fundamentals
- **TcpListener::bind()** claims OS resources - can fail if port in use
- **`listener.incoming()`** is an infinite iterator blocking on connections
- **HTTP is text-based**: Easy to parse with `BufReader` and `.lines()`
- **Request format**: Method + Path + Version, then headers, then blank line, then optional body
