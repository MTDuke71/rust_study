## 🔧 **Technical Insights**

### TCP and HTTP Fundamentals
- **TcpListener::bind()** claims OS resources - can fail if port in use
- **`listener.incoming()`** is an infinite iterator blocking on connections
- **HTTP is text-based**: Easy to parse with `BufReader` and `.lines()`
- **Request format**: Method + Path + Version, then headers, then blank line, then optional body

### File Path Gotcha
- `cargo run --example` executes from workspace root, not package directory
- Examples must use relative paths: `rust_book/Ch21/hello.html`
