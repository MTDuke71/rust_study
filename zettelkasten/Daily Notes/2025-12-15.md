## 🔧 **Technical Insights**

### Thread Pool Architecture
- **Fixed workers** reuse threads instead of spawning per-request
- **MPSC channels** distribute jobs across worker pool
- **`Arc<Mutex<Receiver>>`** allows multiple workers to share single receiver
- **Graceful shutdown** via channel closure when all senders dropped

### Real-World Learning
- Port binding errors (`AddrInUse`) when previous server still running
- Empty connection handling - browsers open/close connections preemptively
- Concurrency testing: `/sleep` endpoint demonstrates non-blocking behavior

### Pathfinding State Space Design
- **Traditional grid pathfinding**: State = position only
- **Rotation-cost pathfinding**: State = (position, direction) pair
- **Mission 6 integration**: `Grid<T>` with tuple indexing and `Coord` conversion
- **Neighbor generation**: 3 options from each state (forward, rotate CW, rotate CCW)
