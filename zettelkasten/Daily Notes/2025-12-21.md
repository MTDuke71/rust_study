## 🔧 **Technical Insights**

### Day 22 PRNG Compiler Optimizations
- **Power-of-2 Magic**: Modulo 2^24 → `and eax, 0xFFFFFF` (3 instructions), multiply by 64 → `shl rax, 6` (1 cycle)
- **Assembly Verification**: cargo-show-asm proves 2.21x speedup (power-of-2 vs prime modulo), 2.15x full PRNG
- **Two-Level HashMap Pattern**: Local per-buyer deduplication + global aggregation prevents double-counting
- **Embarrassingly Parallel**: Part 1 achieves 16.58x speedup with simple `par_iter()` (no shared state)
- **Thread-Local Strategy**: Part 2 requires thread-local HashMaps to avoid mutex contention (2.17x vs 1.97x with Mutex)
- **Iterator Chains**: Functional pipelines replacing imperative loops - building Rust fluency through exposure

### REST API Design Patterns
- **OpenAPI/Swagger auto-generation**: Zero HTML written - entire web UI auto-generated from Rust code annotations
- **Utoipa compile-time docs**: `#[derive(ToSchema)]` and `#[utoipa::path]` macros generate OpenAPI spec
- **API versioning**: `/api/v1` prefix enables future evolution without breaking clients
- **UUIDs as resource IDs**: Globally unique, unpredictable, distributed-system friendly

### Integrator Pattern in Action

### Concurrency Patterns
