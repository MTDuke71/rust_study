## 🎯 Day 16: Proboscidea Volcanium

**Problem**: Maximize pressure released by opening valves in a cave network within a time budget.

### Results
- **Part 1**: 1,638 (30 minutes, solo) - 3.79ms
- **Part 2**: 2,400 (26 minutes, you + elephant) - 1.18ms
- **Combined**: 4.94ms

### Algorithm (3-step approach)

1. **Graph compression**: 55 valves → 16 key nodes (AA + 15 non-zero flow). BFS all-pairs shortest distances eliminates "hallway" nodes.

2. **Bitmask DFS** (Part 1): State = `(position, opened_bitmask, time_remaining)`. Try each unopened valve reachable in time. Pressure = `flow_rate × remaining_time`. Time budget prunes aggressively.

3. **Bitmask partition + SOS DP** (Part 2): Record `best_pressure[mask]` from DFS with 26 min. SOS DP propagates "best over any subset." Then scan all masks: `max(best[m] + best[complement(m)])`.

### Key Insight: NOT Dijkstra
Looks like shortest path but isn't - no single destination, value depends on arrival time, maximizing cumulative reward over ordering. Closer to TSP with time-dependent rewards.

## 🔗 Patterns Worth Remembering

- **Graph compression**: Eliminate noise nodes via BFS precomputation
- **Bitmask DFS**: ~15 items + pruning = sweet spot for exponential search
- **SOS DP (Sum over Subsets)**: O(n × 2^n) propagation enables O(2^n) partition lookup
- **Two-actor partition**: Solve independently, find best disjoint pair
