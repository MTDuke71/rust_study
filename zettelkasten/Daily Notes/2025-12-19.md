## 🔧 **Technical Insights**

### AoC Day 20 - Bidirectional Distance Maps
- **Pattern**: Alternative to traditional meet-in-middle search
- **Key insight**: Pre-compute distances from both start and end
- **Efficiency**: O(1) savings calculation for any cheat path
- **Manhattan distance**: L1-norm creates diamond shapes on discrete grids
- **Path reconstruction**: Follow distance-1 gradient backwards from end to start

### Rust Editions System
- **Purpose**: Controlled introduction of breaking changes without forcing ecosystem-wide updates
- **Key Principle**: Code from different editions can interoperate in the same project
- **Migration**: Automated with `cargo fix --edition` for most changes
- **Current editions**: 2015 (original), 2018 (ergonomic improvements), 2021 (latest)

### Line Intersection Algorithm
- **Orientation test**: Uses cross product to determine clockwise/counterclockwise/collinear
- **Robustness**: Integer arithmetic avoids floating-point precision issues
- **Applications**: Wire crossing (AoC 2019 Day 3), ray tracing, collision detection
- **Performance**: O(1) per check, O(n log n + k) for sweep line bulk intersections
