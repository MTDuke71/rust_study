### Euclidean Algorithm Deep Dive
```rust
fn gcd(mut a: usize, mut b: usize) -> usize {
    while b != 0 {
        let temp = b;
        b = a % b;  // Key: gcd(a,b) = gcd(b, a mod b)
        a = temp;
    }
    a
}
```
- **Complexity**: O(log min(a,b)) - remarkably efficient!
- **Property**: gcd(a,b) = gcd(b, a mod b) reduces problem size by ≥50% each iteration
- **Application**: Foundation for LCM computation: `lcm(a,b) = (a×b) / gcd(a,b)`

### HashMap Graph Representation Pattern
```rust
// Directed graph with labeled edges (L/R)
nodes: HashMap<String, (String, String)>  // node -> (left_neighbor, right_neighbor)
```
- **Why HashMap?** String node IDs (not 0..n integers), O(1) lookup
- **Why tuple?** Exactly 2 neighbors per node (left, right) - fixed structure
- **Mission 5 Integration**: Reusing validated HashMap patterns from mission library

### Modular Arithmetic for Cyclic Instructions
```rust
instruction_idx = (instruction_idx + 1) % instructions.len();
```
- **Pattern**: Repeat sequence "LLR" → L, L, R, L, L, R, ...
- **Mathematics**: `n % m` wraps to [0, m-1] range automatically
- **Application**: Clock arithmetic, circular buffers, repeating patterns
