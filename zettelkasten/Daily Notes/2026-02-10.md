### CPU Simulation Model
**Instruction Set**:
- `noop`: 1 cycle, no effect
- `addx V`: 2 cycles, adds V to X register **after completion**

**Key Insight**: Register updates happen AFTER instruction completes, not during execution
- During cycles 1-2 of `addx 15`: X still holds old value
- After cycle 2 completes: X updates to new value

**Timing Model**:
```
Cycle 1: Begin addx 15 (X=1)
  During cycle 1: X still = 1
Cycle 2: Still executing addx 15 (X=1)
  During cycle 2: X still = 1
  After cycle 2: X becomes 16
Cycle 3: Next instruction starts (X=16)
```

### CRT Rendering Algorithm
**Display**: 40 wide × 6 high (240 pixels total)  
**Sprite**: 3 pixels wide `[X-1, X, X+1]` controlled by X register  
**Drawing**: Each cycle draws ONE pixel at position `(cycle-1) % 40`

**Overlap Detection**:
```rust
let crt_col = (cycle % 40) as i32;
if (x - 1..=x + 1).contains(&crt_col) {
    crt.push('#');  // Sprite visible
} else {
    crt.push('.');  // Sprite not visible
}
```

**Visual Example** (first 20 pixels):

