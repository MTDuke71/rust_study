## 🔧 **Technical Insights**
- **Obsidian Dataview Fix**: Backticks in markdown tables can trigger Dataview inline field parsing
  - Symbols like `=>` and `:` inside backticks are interpreted as field markers
  - **Solution**: Use double quotes (`"=>"`) instead of backticks (`` `=>` ``) in table cells
  - Escaping with backslashes didn't work - quote wrapping was the correct fix
- Topological sort has two equivalent O(V+E) algorithms with different trade-offs:
  - DFS: Elegant recursion, implicit cycle detection
  - Kahn's: Explicit state, better for parallelization
