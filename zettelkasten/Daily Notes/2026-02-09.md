## 🔧 **Technical Insights**

### Critical Learning: Parse-Once Principle Enforcement
**User caught violation**: Initial implementation parsed input twice (once per part)  
**Fix**: Created internal `_with_moves()` functions, `solve()` parses once and passes data  
**Result**: 4% performance improvement + adherence to fundamental 2026 principle

### New Optimization: FxHashSet for Integer Keys
**Discovery**: std::HashMap/HashSet uses SipHash (cryptographic, secure, slower)  
**Alternative**: rustc-hash FxHashSet uses FxHash (non-cryptographic, 2-3× faster for integers)  
**Perfect for AoC**: No security needed, simple numeric keys, massive volume

**Day 9 Impact**:
- ~9,000 total HashSet insertions (6367 + 2536 positions)
- FxHash 2-3× faster per operation
- 20% cumulative speedup (726µs → 568µs, saved 158µs)

**Implementation**:
```rust
use rustc_hash::FxHashSet;  // NOT std::collections::HashSet
let visited = FxHashSet::default();  // NOT ::new()
```

**Cargo.toml**: `rustc-hash = "2.0"`
