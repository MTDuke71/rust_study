## 🔧 **Technical Insights**
- **Trait Objects** enable heterogeneous collections with `Vec<Box<dyn Trait>>`
- **Object Safety** requires: no `Self` in return types, no generics on methods
- **State Pattern Trade-offs**: OOP (runtime flexibility) vs Type States (compile-time safety)
- **Rust's approach**: Composition and traits over classical inheritance
- **Greedy Algorithm Window**: `[start..=(n - remaining)]` ensures enough digits for remaining picks
- **Tie-Breaking Strategy**: Use `.find()` for first occurrence, not `max_by_key()` which returns last
