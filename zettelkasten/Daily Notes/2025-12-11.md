### AoC 2025 Day 11: Network (Graph Path Counting) ✅
**Problem**: Count paths in directed acyclic graph with constraints
- **Part 1**: Count all paths from "you" to "out" → **466 paths**
- **Part 2**: Count paths from "svr" to "out" visiting BOTH "dac" AND "fft" → **549,705,036,748,518 paths** (549 trillion!)

**Key Algorithm Evolution**:
1. **Part 1**: Simple DFS with memoization `HashMap<String, usize>` → Instant ✅
2. **Part 2 v1**: Naive full-path tracking with `Vec<String>` → **Timeout after 10s** ❌
3. **Part 2 v2**: State-based memoization with `HashMap<(String, usize), usize>` → **Instant** ✅

**Critical Insight - Composite State Representation**:
```rust
// State = (current_node, visited_required_nodes_bitmask)
// For 2 required nodes: 4 possible states per node
0b00 (0): visited neither dac nor fft
0b01 (1): visited dac only  
0b10 (2): visited fft only
0b11 (3): visited both (valid path!)
```

**Bitmask Update Logic**:
```rust
let mut new_mask = visited_mask;
for (i, &req) in required.iter().enumerate() {
    if current == req {
        new_mask |= 1 << i;  // Set bit i when visiting required[i]
    }
}
```

**Mission 8 Integration Attempt**:
- **Tried**: Use Mission 8's `Graph` trait for `HashMap<String, Vec<String>>`
- **Blocked**: Trait requires `type Node: Copy`, but `String` is not `Copy`
- **Resolution**: Used HashMap methods directly (`.get()`, `.contains_key()`)
- **Learning**: Mission libraries have design constraints, adapt when needed

## 🔧 **Technical Insights**

### State Representation Prevents Exponential Blowup
**Problem**: 549 trillion paths exist in the graph - can't enumerate them all
**Solution**: Memoization with composite state `(node, visited_set)` instead of full path tracking
- **Complexity**: O(V × 2^R) where R = required nodes (O(V × 4) for 2 required)
- **Result**: Compute each state once, reuse across recursive calls

### Bitmask for Small Set Membership
When tracking 2-5 items, bit flags are:
- **Compact**: Single `usize` instead of `HashSet<String>`
- **Fast**: Bitwise operations (`|=`, `<<`, `&`) instead of hash lookups
- **Natural indexing**: Bit i corresponds to required[i]

### Performance Debugging Pattern
1. **Symptom**: Timeout after 10 seconds (exit code 0xc000013a)
2. **Diagnosis**: Exponential path exploration without memoization
3. **Recognition**: User immediately understood → "Ok" (no explanation needed)
4. **Solution**: Redesign state representation from path to visited_set
5. **Validation**: Same test results, instant performance

### HashMap Methods Without Trait Abstraction
```rust
// Direct HashMap use when traits don't fit:
graph.get(node).unwrap_or(&vec![])  // Get neighbors
graph.contains_key(node)             // Node existence check
```
Works fine for simple adjacency list - trait abstraction not always necessary.
