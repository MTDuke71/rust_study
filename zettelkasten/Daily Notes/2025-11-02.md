### Implementation Details:

**Data Structure**:
```rust
pub struct UnionFind {
    parent: Vec<usize>,  // Parent pointers
    rank: Vec<usize>,    // Union by rank
    size: Vec<usize>,    // Component sizes
    count: usize,        // Number of sets
}
```

**Optimizations**:
- ✅ Path compression in `find()`
- ✅ Union by rank in `union()`
- ✅ Amortized O(α(n)) complexity (inverse Ackermann)

**Operations**:
- `new(n)` - Initialize n disjoint sets - O(n)
- `find(x)` - Find root of x with path compression - O(α(n))
- `union(x, y)` - Merge sets containing x and y - O(α(n))
- `connected(x, y)` - Check if x and y in same set - O(α(n))
- `count()` - Number of disjoint sets - O(1)
- `size(x)` - Size of set containing x - O(α(n))
