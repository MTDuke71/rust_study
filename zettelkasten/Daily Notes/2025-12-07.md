## 🔧 **Technical Insights**

### Pattern Locations Overview (Ch19.1)
1. **match expressions**: Exhaustive pattern matching (used in Day 7 for Cell type branching)
2. **if let**: Single pattern with optional else (used for cache lookups, grid bounds checking)
3. **while let**: Conditional loops based on pattern match (used in BFS queue processing)
4. **for loops**: Iterator destructuring
5. **let statements**: Variable binding patterns (tuple destructuring: `let (grid, start) = parse_manifold()`)
6. **Function parameters**: Destructure arguments directly

**Problem**: Simulate quantum timeline splitting when tachyon beams hit splitters

   - Memoization reduces O(2^n) to O(n) by caching subproblem results
