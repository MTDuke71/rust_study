# Advent of Code 2023

*Two-phase workflow: Solve (get stars) → Polish (production quality)*

---

## 📋 Status

**Planned Start**: January 2025  
**Strategy**: Two-phase workflow (solve fast, polish later)

**Notable Optimizations**: Day 3 spatial indexing (246.8x speedup) - see [[spatial-indexing-pattern]]

---

## 🎯 Two-Phase Workflow

### **Phase 1: Solve** (<45 minutes per day)
- Example test first → implement → verify → submit
- Get both stars as quickly as possible
- Quick commit with basic solution
- Basic error handling only

### **Phase 2: Polish** (<1 hour per problem)
- Mission integration (reuse existing data structures)
- Comprehensive test suite
- Performance benchmarks (if >10ms)
- Visualization (if complex problem)
- Summary.md entry (100-150 lines)
- Zettelkasten note (if novel pattern discovered)

### **Weekly Review**
- Extract patterns across days
- Identify mission candidates
- Update pattern recognition framework

See: [[.github/AOC2023_WORKFLOW_GUIDE]] for complete methodology
