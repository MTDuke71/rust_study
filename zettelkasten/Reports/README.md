# 📊 Reports Directory

This directory contains automated reports and analysis files for the zettelkasten knowledge management system.

## 📁 Files in this Directory

### [[Orphans.md]]
- **Purpose**: Identifies files that are not well-connected to the knowledge graph
- **Contains**: Dataview queries showing files with no incoming/outgoing links
- **Use Case**: Find content that needs better integration into the zettelkasten

### [[Broken Links Report.md]]
- **Purpose**: Tracks all broken wiki links (references to non-existent files)
- **Contains**: Statistics and lists of missing pages that are frequently referenced
- **Use Case**: Identify high-priority concepts that should be created

### [[Link Validation Report.md]]
- **Purpose**: Automated link health monitoring
- **Contains**: Overall link statistics and validation for key files like zettel-index
- **Use Case**: Maintain link integrity across the knowledge base
