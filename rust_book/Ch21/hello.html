🎓 Learning Objectives:

This project demonstrates:

  • Ownership & Borrowing: Managing TcpStream connections
  • Concurrency: Thread pool with message passing (MPSC)
  • Smart Pointers: Arc<Mutex<T>> for shared state
  • Traits: FnOnce + Send + 'static for thread-safe closures
  • RAII: Drop trait for graceful shutdown
