# Problem 36: Double-base Palindromes

**Difficulty**: 5%
**Category**: Number Theory / Palindromes / Base Representation

## Problem Statement

The decimal number, 585 = 1001001001₂ (binary), is palindromic in both bases.

Find the sum of all numbers, less than one million, which are palindromic in
base 10 and base 2.

(Please note that the palindromic number, in either base, may not include
leading zeros.)

## Examples

- **585** → decimal "585" reverses to "585" ✓; binary "1001001001" reverses to "1001001001" ✓
- **9** → decimal "9" ✓; binary "1001" ✓
- **33** → decimal "33" ✓; binary "100001" ✓

## Constraints

- n < 1,000,000
- No leading zeros in either representation (so trailing zeros are forbidden;
  in particular every solution is **odd**)
- Answer: **872187**

## Performance

| Metric | Value |
|--------|-------|
| Time | < 5 ms (release) |
| Search space | 500,000 odd candidates |
| Algorithm | Integer reversal (no string allocation) |
