# Problem 33: Digit Cancelling Fractions

**Difficulty**: 5%
**Category**: Number Theory / Fractions

## Problem Statement

The fraction 49/98 is a curious fraction, as an inexperienced mathematician in
attempting to simplify it may incorrectly believe that:

> 49/98 = 4/8

which is correct, by cancelling the 9s.

We shall consider fractions like, 30/50 = 3/5, to be trivial examples.

There are exactly four non-trivial examples of this type of fraction, less
than one in value, and containing two digits in the numerator and denominator.

If the product of these four fractions is given in its lowest common terms,
find the value of the denominator.

## Examples

The four non-trivial digit-cancelling fractions:
- 16/64 = 1/4 (cancel 6s)
- 19/95 = 1/5 (cancel 9s)
- 26/65 = 2/5 (cancel 6s)
- 49/98 = 4/8 = 1/2 (cancel 9s)

Product: (16 · 19 · 26 · 49) / (64 · 95 · 65 · 98) = 1/100.

## Constraints

- Numerator and denominator each have exactly 2 digits
- Fraction is strictly less than 1 (n < d)
- Excludes "trivial" trailing-zero cancellations like 30/50
- Answer: **100**

## Performance

| Metric | Value |
|--------|-------|
| Time | ~8.6 µs |
| Search space | C(90, 2) + diagonal ≈ 4005 pairs |
| Algorithm | Brute force with cross-multiplication |
