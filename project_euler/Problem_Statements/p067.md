# Problem 67: Maximum Path Sum II

**Difficulty**: 20%
**Category**: Dynamic Programming / Graph Theory (DAG)

## Problem Statement

Find the maximum total from top to bottom in a 100-row triangle loaded from
a file. The same rule applies: at each step move to one of the two adjacent
numbers in the row below.

**NOTE**: This is a much more difficult version of Problem 18. It is not
possible to try every route as there are 2^99 altogether! If you could check
one trillion (10^12) routes every second it would take over twenty billion
years to check them all. There is an efficient algorithm to solve it.
