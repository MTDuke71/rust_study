# Problem 11: Largest Product in a Grid

**Difficulty Rating:** 5%

## Problem Statement

In the 20×20 grid below, four numbers along a diagonal line have been marked with **.

```
08 02 22 97 38 15 00 40 00 75 04 05 07 78 52 12 50 77 91 08
49 49 99 40 17 81 18 57 60 87 17 40 98 43 69 48 04 56 62 00
81 49 31 73 55 79 14 29 93 71 40 67 53 88 30 03 49 13 36 65
52 70 95 23 04 60 11 42 69 24 68 56 01 32 56 71 37 02 36 91
22 31 16 71 51 67 63 89 41 92 36 54 22 40 40 28 66 33 13 80
24 47 32 60 99 03 45 02 44 75 33 53 78 36 84 20 35 17 12 50
32 98 81 28 64 23 67 10 **26** 38 40 67 59 54 70 66 18 38 64 70
67 26 20 68 02 62 12 20 95 **63** 94 39 63 08 40 91 66 49 94 21
24 55 58 05 66 73 99 26 97 17 **78** 78 96 83 14 88 34 89 63 72
21 36 23 09 75 00 76 44 20 45 35 **14** 00 61 33 97 34 31 33 95
78 17 53 28 22 75 31 67 15 94 03 80 04 62 16 14 09 53 56 92
```

The product of these numbers is 26 × 63 × 78 × 14 = 1,788,696.

What is the greatest product of four adjacent numbers in the same direction (up, down, left, right, or diagonally) in the 20×20 grid?

## Solution

**Answer:** 70,600,674

## Approach

### Diagonal Pattern Visualization

```
Grid indices (row, col):
    0   1   2   3
0  [A] [B] [C] [D]
1  [E] [F] [G] [H]
2  [I] [J] [K] [L]
3  [M] [N] [O] [P]

Diagonal Down-Right (↘) from A:
  A(0,0) → F(1,1) → K(2,2) → P(3,3)
  Pattern: row+i, col+i

Diagonal Down-Left (↙) from D:
  D(0,3) → G(1,2) → J(2,1) → M(3,0)
  Pattern: row+i, col-i
```

### Algorithm

1. **Parse grid** from text format
2. **For each cell**, check 4 directions:
   - Horizontal (→): `grid[row][col+i]`
   - Vertical (↓): `grid[row+i][col]`
   - Diagonal ↘: `grid[row+i][col+i]`
   - Diagonal ↙: `grid[row+i][col-i]`
3. **Track maximum** product across all valid sequences

### Implementation

```rust
fn product_at(grid: &[Vec<u32>], row: usize, col: usize, dir: Direction) -> Option<u64> {
    let rows = grid.len();
    let cols = grid[0].len();
    
    match dir {
        Direction::Horizontal => {
            if col + 3 < cols {
                Some(grid[row][col] as u64
                    * grid[row][col + 1] as u64
                    * grid[row][col + 2] as u64
                    * grid[row][col + 3] as u64)
            } else { None }
        }
        Direction::DiagonalDownRight => {
            if row + 3 < rows && col + 3 < cols {
                Some(grid[row][col] as u64
                    * grid[row + 1][col + 1] as u64
                    * grid[row + 2][col + 2] as u64
                    * grid[row + 3][col + 3] as u64)
            } else { None }
        }
        Direction::DiagonalDownLeft => {
            if row + 3 < rows && col >= 3 {
                Some(grid[row][col] as u64
                    * grid[row + 1][col - 1] as u64
                    * grid[row + 2][col - 2] as u64
                    * grid[row + 3][col - 3] as u64)
            } else { None }
        }
        // ... vertical similar ...
    }
}
```

## Complexity

- **Time:** O(n²) where n = grid size (20)
  - 400 cells, each checks up to 4 directions = ~1,600 checks
- **Space:** O(n²) to store grid
- **Performance:** ~6.8 μs

## Key Insights

1. **Bounds checking is critical**: Different directions have different valid ranges
   - Horizontal: `col + 3 < cols`
   - Vertical: `row + 3 < rows`
   - Diagonal ↘: Both row and col must have room
   - Diagonal ↙: `row + 3 < rows && col >= 3`

2. **Direction patterns**:
   - Moving right: increment column only
   - Moving down: increment row only  
   - Diagonal down-right: increment both (same direction)
   - Diagonal down-left: increment row, decrement column (opposite directions)

3. **No need to check upward**: Checking down from (0,0) is same as checking up from (3,3)

## Testing

```rust
#[test]
fn test_diagonal_down_right() {
    let grid = vec![
        vec![1, 2, 3, 4],
        vec![5, 6, 7, 8],
        vec![9, 10, 11, 12],
        vec![13, 14, 15, 16],
    ];
    // (0,0) → (1,1) → (2,2) → (3,3): 1*6*11*16 = 1,056
    assert_eq!(product_at(&grid, 0, 0, Direction::DiagonalDownRight), Some(1056));
}

#[test]
fn test_diagonal_down_left() {
    let grid = vec![
        vec![1, 2, 3, 4],
        vec![5, 6, 7, 8],
        vec![9, 10, 11, 12],
        vec![13, 14, 15, 16],
    ];
    // (0,3) → (1,2) → (2,1) → (3,0): 4*7*10*13 = 3,640
    assert_eq!(product_at(&grid, 0, 3, Direction::DiagonalDownLeft), Some(3640));
}
```
