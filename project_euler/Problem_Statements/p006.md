# Problem 6: Sum Square Difference

**Difficulty**: Easy  
**Published**: October 19, 2001

## Problem Statement

The sum of the squares of the first ten natural numbers is:

1² + 2² + ... + 10² = 385

The square of the sum of the first ten natural numbers is:

(1 + 2 + ... + 10)² = 55² = 3025

Hence the difference between the sum of the squares of the first ten natural numbers and the square of the sum is:

3025 - 385 = 2640

**Find the difference between the sum of the squares of the first one hundred natural numbers and the square of the sum.**

## Examples

**n = 10**:
- Sum of squares: 1² + 2² + 3² + ... + 10² = 385
- Square of sum: (1 + 2 + 3 + ... + 10)² = 55² = 3025
- Difference: 3025 - 385 = 2640

## Constraints

- n = 100 (first one hundred natural numbers)
- All intermediate calculations fit in standard integer types

## Approach Hints

1. **Brute force**: Calculate both sums directly using loops
2. **Mathematical formulas**: Use closed-form expressions
   - Sum of first n numbers: n(n+1)/2
   - Sum of squares: n(n+1)(2n+1)/6
3. **Direct calculation**: O(1) time using formulas vs O(n) iterative

## Mathematical Insights

### Sum Formulas

**Sum of first n natural numbers**:
```
1 + 2 + 3 + ... + n = n(n+1)/2
```

**Sum of squares of first n natural numbers**:
```
1² + 2² + 3² + ... + n² = n(n+1)(2n+1)/6
```

### Derivation

For n = 100:
- Sum: 100(101)/2 = 5050
- Square of sum: 5050² = 25,502,500
- Sum of squares: 100(101)(201)/6 = 338,350
- Difference: 25,502,500 - 338,350 = 25,164,150

### Why the Difference is Always Positive

For n > 1, the square of the sum is always greater than the sum of squares because:
- (a + b)² = a² + 2ab + b²
- The cross-product terms (2ab) make the square of sum larger

## Complexity

- **Brute force**: O(n) - iterate through all numbers
- **Formula-based**: O(1) - constant time calculation
