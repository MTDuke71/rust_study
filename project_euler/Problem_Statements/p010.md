# Problem 10: Summation of Primes

**Difficulty Rating:** 5%

## Problem Statement

The sum of the primes below 10 is 2 + 3 + 5 + 7 = 17.

Find the sum of all the primes below two million.

## Solution

**Answer:** 142,913,828,922

## Approach

Used **Sieve of Eratosthenes** with memory optimization:
- Only track odd numbers (2 handled separately) - saves 50% memory
- Sieve marks composites up to √n
- Sum primes during final iteration

## Implementation

Location: `src/problems/p010.rs`

```rust
pub fn sum_primes_below(limit: usize) -> u64 {
    if limit <= 2 {
        return 0;
    }
    
    let mut sum = 2u64; // Start with 2 (only even prime)
    
    if limit <= 3 {
        return sum;
    }
    
    // Sieve for odd numbers only: index i represents (2*i + 3)
    let sieve_size = (limit - 1 - 3) / 2 + 1;
    let mut is_prime = vec![true; sieve_size];
    
    let sqrt_limit = (limit as f64).sqrt() as usize;
    
    for i in 0..sieve_size {
        if is_prime[i] {
            let prime = 2 * i + 3;
            
            if prime > sqrt_limit {
                break;
            }
            
            // Mark multiples as composite
            let start = (prime * prime - 3) / 2;
            for j in (start..sieve_size).step_by(prime) {
                is_prime[j] = false;
            }
        }
    }
    
    // Sum all primes
    for i in 0..sieve_size {
        if is_prime[i] {
            sum += (2 * i + 3) as u64;
        }
    }
    
    sum
}
```

## Complexity

- **Time:** O(n log log n) - Sieve of Eratosthenes
- **Space:** O(n/2) - only track odd numbers
- **Performance:** ~1.1 ms for n = 2,000,000

## Key Insights

1. **Sieve is essential** - trial division would be O(n√n), far too slow for 2 million
2. **Memory optimization** - odd-only sieve halves memory usage
3. **Sum during iteration** - no need to store all primes explicitly
4. **Index mapping** - careful arithmetic to map array index ↔ actual prime value
