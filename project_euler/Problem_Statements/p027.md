# Problem 27: Quadratic Primes

**Difficulty**: 5%
**Category**: Number Theory / Prime Generation

## Problem Statement

Euler discovered the remarkable quadratic formula:

> n² + n + 41

It turns out that the formula will produce 40 primes for the consecutive
integer values 0 ≤ n ≤ 39. However, when n = 40, 40² + 40 + 41 = 41²,
which is divisible by 41.

The incredible formula n² − 79n + 1601 produces 80 primes for 0 ≤ n ≤ 79.
(Note: -79 and 1601 are both related to Euler's formula since
1601 = (-79)² + (-79) + 41.)

Considering quadratics of the form n² + an + b, where |a| < 1000 and |b| ≤ 1000:

Find the product of the coefficients, a and b, for the quadratic expression
that produces the maximum number of primes for consecutive values of n,
starting with n = 0.

## Examples

- n² + n + 41: produces 40 consecutive primes (Euler's discovery)
- n² − 79n + 1601: produces 80 consecutive primes

## Mathematical Foundation

Key search space reductions:
- **b must be prime**: f(0) = b, and b must be prime
- **1 + a + b must be prime**: f(1) = 1 + a + b, constraining a

This reduces ~4M pairs to ~336K (168 primes × 2000 values of a).

## Constraints

- |a| < 1000, |b| ≤ 1000
- Answer: **-59231** (a = -61, b = 971, producing 71 consecutive primes)

## Performance

| Metric | Value |
|--------|-------|
| Time | 3.27 ms |
| Search space | ~168 primes for b × ~2000 values of a |
| Winning formula | n² − 61n + 971 (71 consecutive primes) |
