# Problem 14: Longest Collatz Sequence

**Difficulty**: 5%
**Category**: Number Theory, Dynamic Programming

## Problem Statement

The following iterative sequence is defined for the set of positive integers:

- n → n/2 (n is even)
- n → 3n + 1 (n is odd)

Starting with 13, we generate:

```
13 → 40 → 20 → 10 → 5 → 16 → 8 → 4 → 2 → 1
```

This sequence contains **10 terms**. Although unproven (the Collatz Conjecture), it is thought that all starting numbers finish at 1.

**Which starting number, under one million, produces the longest chain?**

**NOTE**: Once the chain starts, terms are allowed to go above one million.

## Examples

- Starting at 13: 10 terms
- Starting at 9: 20 terms (longest under 10)
- Starting at 1: 1 term

## Constraints

- Target: Under 1,000,000 (exclusive)
- Chain values may exceed 1,000,000
