## Problem Statement

Work out the first ten digits of the sum of the following one-hundred 50-digit numbers.

[100 numbers provided in input - see source code]

---

## Solution Approach

### Key Insight

Since we only need the **first 10 digits** of the sum, we don't need arbitrary precision arithmetic for the full 50-digit numbers. 

### Mathematical Observation

When summing 100 numbers of 50 digits each:
- Maximum sum ≈ 100 × 10^50 ≈ 10^52 (a 52-digit number)
- Carries can propagate at most a few digits
- Taking the first ~15 digits of each number is sufficient to ensure the first 10 digits of the sum are accurate

### Algorithm

```
1. For each 50-digit number:
   - Extract first 15 digits
   - Parse as u128 (can hold up to 39 decimal digits)

2. Sum all these truncated numbers

3. Convert sum to string and extract first 10 digits
```

### Why This Works

- **Carry propagation**: With 100 numbers, worst-case carry from digit 16 onward is bounded
- **u128 capacity**: Summing 100 numbers of ~15 digits each fits comfortably in u128
- **Accuracy guaranteed**: The first 10 digits of the truncated sum match the first 10 digits of the full sum

---

## Complexity Analysis

- **Time**: O(n) where n = 100 (number of inputs)
  - Parse each number: O(1) per number
  - Sum: O(n)
  - Extract digits: O(1)

- **Space**: O(1) for computation
  - Input storage is O(n × m) where m = 50 digits per number
  - But computation only uses a single u128 accumulator

## Implementation

```rust
pub fn first_ten_digits_of_sum() -> String {
    let sum: u128 = NUMBERS
        .lines()
        .map(|line| line.trim())
        .filter(|line| !line.is_empty())
        .map(|trimmed| {
            // Take first 15 digits
            let prefix = if trimmed.len() > 15 {
                &trimmed[..15]
            } else {
                trimmed
            };
            prefix.parse::<u128>().unwrap()
        })
        .sum();

    let sum_str = sum.to_string();
    sum_str[..10].to_string()
}
```

## Alternative Approaches

### Naive Approach: String Addition

Manually implement addition with carry propagation:

```
- Start from rightmost digit
- Add corresponding digits across all 100 numbers
- Propagate carries left
- Extract first 10 digits of result
```

**Complexity**: O(n × m) where n = 100, m = 50  
**Performance**: ~10-20× slower due to manual carry handling

### Arbitrary Precision Approach

Use libraries like `num-bigint`:

```rust
use num_bigint::BigUint;

let sum: BigUint = NUMBERS
    .lines()
    .map(|line| line.parse::<BigUint>().unwrap())
    .sum();
```

**Complexity**: O(n × m)  
**Performance**: Slower due to heap allocations and general-purpose arithmetic

### Our Approach: Truncation + u128

**Why it's optimal**:
✅ No heap allocations  
✅ Uses fast native u128 arithmetic  
✅ Minimal parsing overhead  
✅ Mathematically sound for this problem

---

## Mathematical Justification

### Carry Bound Proof

When summing k numbers, each with digit d_i at position i:

```
Sum at position i = Σ(d_i) + carry_from_(i-1)
```

For position i ≥ 16 (beyond our 15-digit truncation):
- Each d_i ∈ [0, 9]
- Maximum Σ(d_i) = 100 × 9 = 900
- Maximum carry from previous position = 90

Total = 900 + 90 = 990

This contributes at most **2 digits of carry** to higher positions.

Therefore, taking 15 digits gives us a **5-digit safety margin** for the first 10 digits - more than sufficient!
