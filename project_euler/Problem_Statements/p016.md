# Problem 16: Power Digit Sum

**Difficulty**: 5%
**Category**: Big Number Arithmetic, Digit Manipulation

## Problem Statement

2^15 = 32768 and the sum of its digits is 3 + 2 + 7 + 6 + 8 = 26.

What is the sum of the digits of the number 2^1000?

## Examples

- 2^15 = 32768, digit sum = 3 + 2 + 7 + 6 + 8 = 26
- 2^10 = 1024, digit sum = 1 + 0 + 2 + 4 = 7

## Constraints

- 2^1000 has ~302 decimal digits (log10(2) * 1000 ≈ 301.03)
- Far exceeds u64 (~18 digits) and u128 (~38 digits)
- Requires arbitrary precision arithmetic
