# Problem 7: 10001st Prime

**Difficulty**: Easy  
**Published**: December 28, 2001

## Problem Statement

By listing the first six prime numbers: 2, 3, 5, 7, 11, and 13, we can see that the 6th prime is 13.

**What is the 10,001st prime number?**

## Examples

**First few primes**:
- 1st prime: 2
- 2nd prime: 3
- 3rd prime: 5
- 4th prime: 7
- 5th prime: 11
- 6th prime: 13

## Constraints

- Find the 10,001st prime (index starts at 1)
- Need to handle primes up to approximately 105,000 (upper bound estimate)

## Approach Hints

1. **Brute force trial division**: Test each number for primality
2. **Sieve of Eratosthenes**: Generate all primes up to upper bound
3. **Trial division with optimizations**:
   - Only test odd numbers (after 2)
   - Only divide by primes up to √n
   - Stop when count reaches 10,001

## Mathematical Insights

### Prime Number Theorem

The nth prime is approximately:
```
p(n) ≈ n × ln(n)
```

For n = 10,001:
```
p(10,001) ≈ 10,001 × ln(10,001) ≈ 10,001 × 9.21 ≈ 92,109
```

So we need to check primes up to approximately 92,000-110,000.

### More Precise Bounds

For n ≥ 6, tighter bounds exist:
```
n(ln(n) + ln(ln(n)) - 1) < p(n) < n(ln(n) + ln(ln(n)))
```

For n = 10,001:
- Lower bound: ≈ 104,320
- Upper bound: ≈ 114,320

### Primality Testing

To check if n is prime:
1. If n ≤ 1: not prime
2. If n = 2: prime
3. If n is even: not prime
4. Test divisibility by odd numbers from 3 to √n

**Optimization**: Only test divisibility by previously found primes.

## Algorithms

### Algorithm 1: Trial Division

```
primes = [2]
candidate = 3
while len(primes) < 10001:
    is_prime = true
    for p in primes:
        if p * p > candidate:
            break
        if candidate % p == 0:
            is_prime = false
            break
    if is_prime:
        primes.append(candidate)
    candidate += 2
return primes[10000]
```

### Algorithm 2: Sieve of Eratosthenes

```
limit = estimate_upper_bound(10001)
sieve = [true] * limit
sieve[0] = sieve[1] = false

for i in 2..sqrt(limit):
    if sieve[i]:
        for j in (i*i)..limit step i:
            sieve[j] = false

primes = [i for i, is_prime in enumerate(sieve) if is_prime]
return primes[10000]
```

## Complexity

- **Trial division**: O(n² / ln(n)) - check n numbers, each takes O(n/ln(n)) divisions
- **Sieve**: O(n log log n) - much faster for generating many primes
- **Space**: Sieve uses O(n) memory, trial division uses O(n/ln(n))

## Performance Considerations

- Sieve is faster if you need many primes
- Trial division uses less memory
- For finding just the nth prime, trial division with optimizations is often sufficient
