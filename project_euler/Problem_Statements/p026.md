# Problem 26: Reciprocal Cycles

**Difficulty**: 5%
**Category**: Number Theory / Modular Arithmetic

## Problem Statement

A unit fraction contains 1 in the numerator. The decimal representation of
the unit fractions with denominators 2 to 10 are given:

```
1/2  = 0.5
1/3  = 0.(3)
1/4  = 0.25
1/5  = 0.2
1/6  = 0.1(6)
1/7  = 0.(142857)
1/8  = 0.125
1/9  = 0.(1)
1/10 = 0.1
```

Where 0.1(6) means 0.1666..., and has a 1-digit recurring cycle. It can be
seen that 1/7 has a 6-digit recurring cycle.

Find the value of d < 1000 for which 1/d contains the longest recurring
cycle in its decimal fraction part.

## Examples

- 1/7 = 0.(142857), cycle length 6 (= d-1, maximum possible)
- 1/3 = 0.(3), cycle length 1
- 1/6 = 0.1(6), cycle length 1 (factor of 2 gives prefix, factor of 3 gives cycle)

## Mathematical Foundation

The cycle length of 1/d equals the **multiplicative order** of 10 mod d:
the smallest k such that 10^k ≡ 1 (mod d).

Maximum cycle d-1 occurs when d is prime and 10 is a **primitive root** mod d.

## Constraints

- Range: d < 1000
- Answer: **983** (cycle length 982)

## Performance

| Metric | Value |
|--------|-------|
| Time | 216 µs |
| Approach | Multiplicative order via modular simulation |
| Complexity | O(n × d_max) |
