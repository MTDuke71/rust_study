# Problem 29: Distinct Powers

**Difficulty**: 5%
**Category**: Number Theory / Combinatorics

## Problem Statement

Consider all integer combinations of a^b for 2 ≤ a ≤ 100 and 2 ≤ b ≤ 100:

> 2², 2³, ..., 2¹⁰⁰, 3², 3³, ..., 3¹⁰⁰, ..., 100², 100³, ..., 100¹⁰⁰

If they are then placed in numerical order, with any repeats removed, how
many distinct terms are in the resulting sequence?

## Examples

- For 2 ≤ a ≤ 5 and 2 ≤ b ≤ 5, the 15 distinct terms are:
  4, 8, 9, 16, 25, 27, 32, 64, 81, 125, 243, 256, 625, 1024, 3125

- The duplicate: 4² = 2⁴ = 16 (counted once)

## Mathematical Foundation

Duplicates arise when bases are powers of smaller bases:
- 4 = 2², so 4^b = 2^(2b) — duplicates terms from base 2
- 8 = 2³, so 8^b = 2^(3b) — more duplicates from base 2
- 9 = 3², so 9^b = 3^(2b) — duplicates terms from base 3

**Canonical form**: Reduce each a to its smallest base r (where a = r^k),
then a^b = r^(k×b). Two terms are equal iff they have the same canonical form.

## Constraints

- 2 ≤ a ≤ 100, 2 ≤ b ≤ 100
- Answer: **9183** (out of 99 × 99 = 9801 total pairs)
