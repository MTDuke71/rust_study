# Problem 9: Special Pythagorean Triplet

**Difficulty**: 5%  
**Category**: Number Theory, Pythagorean Triplets

## Problem Statement

A Pythagorean triplet is a set of three natural numbers, $a < b < c$, for which:

$$a^2 + b^2 = c^2$$

For example, $3^2 + 4^2 = 9 + 16 = 25 = 5^2$.

There exists **exactly one** Pythagorean triplet for which $a + b + c = 1000$.

**Find the product $abc$.**

## Examples

**Classic Pythagorean triplet**:
- $a = 3, b = 4, c = 5$
- Check: $3^2 + 4^2 = 9 + 16 = 25 = 5^2$ ✓
- Sum: $3 + 4 + 5 = 12$

**Another example**:
- $a = 5, b = 12, c = 13$
- Check: $5^2 + 12^2 = 25 + 144 = 169 = 13^2$ ✓
- Sum: $5 + 12 + 13 = 30$

## Constraints

- $a < b < c$ (strictly increasing)
- $a^2 + b^2 = c^2$ (Pythagorean theorem)
- $a + b + c = 1000$ (target sum)
- All are natural numbers (positive integers)

## Approach

### Method 1: Brute Force with Constraints

Search space reduction:
1. $a < b < c$ means $a$ is smallest
2. $a + b + c = 1000$ means $a < 1000/3 \approx 333$
3. For given $a$, $b < (1000-a)/2$
4. Calculate $c = 1000 - a - b$
5. Check if $a^2 + b^2 = c^2$

**Complexity**: $O(n^2)$ where $n = 1000$

### Method 2: Algebraic Optimization

From constraints:
- $c = 1000 - a - b$
- $a^2 + b^2 = c^2 = (1000 - a - b)^2$

Expand and simplify:
$$a^2 + b^2 = 1000000 - 2000a - 2000b + a^2 + 2ab + b^2$$
$$0 = 1000000 - 2000a - 2000b + 2ab$$
$$2000(a + b) = 1000000 + 2ab$$
$$a + b = 500 + \frac{ab}{1000}$$

This allows searching with one variable constrained by the other.

### Method 3: Pythagorean Triple Formula (Advanced)

Use Euclid's formula for generating Pythagorean triplets:
- $a = m^2 - n^2$
- $b = 2mn$  
- $c = m^2 + n^2$

Where $m > n > 0$, $\gcd(m,n) = 1$, and $m - n$ is odd.

For scaled triplets: multiply by factor $k$
