# Project Euler Problem 12: Highly Divisible Triangular Number

**Difficulty:** 5%  
**Solved:** Yes  
**Answer:** 76,576,500  
**Performance:** ~720 μs

## Problem Statement

The sequence of triangle numbers is generated by adding the natural numbers. So the 7th triangle number would be 1 + 2 + 3 + 4 + 5 + 6 + 7 = 28. The first ten terms would be:

1, 3, 6, 10, 15, 21, 28, 36, 45, 55, ...

Let us list the factors of the first seven triangle numbers:

```
 1: 1
 3: 1,3
 6: 1,2,3,6
10: 1,2,5,10
15: 1,3,5,15
21: 1,3,7,21
28: 1,2,4,7,14,28
```

We can see that 28 is the first triangle number to have over five divisors.

**What is the value of the first triangle number to have over five hundred divisors?**

## Solution Approach

### Naive Approach (Too Slow)
Generate triangle numbers T(n) = n(n+1)/2 and count divisors by testing all numbers up to √T(n). This is O(√T(n)) per triangle number, and since T(n) grows quadratically, becomes very slow.

### Optimized Approach: Prime Factorization + Divisor Formula

**Key Mathematical Insight:**

If n = p₁^a₁ × p₂^a₂ × ... × pₖ^aₖ (prime factorization), then:

**Number of divisors τ(n) = (a₁ + 1)(a₂ + 1)...(aₖ + 1)**

**Why it works:**
- Each divisor chooses exponent 0 ≤ e₁ ≤ a₁ for prime p₁
- (a₁ + 1) choices for p₁, (a₂ + 1) choices for p₂, etc.
- Total combinations = product of choices

**Example:** 28 = 2² × 7¹
- Exponents for 2: {0, 1, 2} → 3 choices
- Exponents for 7: {0, 1} → 2 choices
- Total divisors: 3 × 2 = 6 ✓ (1, 2, 4, 7, 14, 28)

### Additional Optimization: Coprimality Property

Triangle numbers: T(n) = n(n+1)/2

**Key observation:** n and (n+1) are consecutive, so **gcd(n, n+1) = 1** (coprime!)

**Consequence:**
- If n is even: T(n) = (n/2) × (n+1)
  - τ(T(n)) = τ(n/2) × τ(n+1)
- If n is odd: T(n) = n × ((n+1)/2)
  - τ(T(n)) = τ(n) × τ((n+1)/2)

**Benefit:** Factor two smaller coprime numbers instead of the full triangle number!

## Implementation

```rust
pub fn count_divisors(mut n: u64) -> u64 {
    // Prime factorization with divisor counting
    let mut divisor_count = 1u64;
    
    // Factor of 2
    if n % 2 == 0 {
        let mut exponent = 0;
        while n % 2 == 0 {
            exponent += 1;
            n /= 2;
        }
        divisor_count *= exponent + 1;
    }
    
    // Odd factors
    let mut factor = 3u64;
    while factor * factor <= n {
        if n % factor == 0 {
            let mut exponent = 0;
            while n % factor == 0 {
                exponent += 1;
                n /= factor;
            }
            divisor_count *= exponent + 1;
        }
        factor += 2;
    }
    
    // Remaining n is prime (exponent = 1)
    if n > 1 {
        divisor_count *= 2; // (1 + 1)
    }
    
    divisor_count
}

pub fn first_triangle_with_divisors(min_divisors: u64) -> u64 {
    let mut n = 1u64;
    
    loop {
        // Use coprimality property
        let divisor_count = if n % 2 == 0 {
            count_divisors(n / 2) * count_divisors(n + 1)
        } else {
            count_divisors(n) * count_divisors((n + 1) / 2)
        };
        
        if divisor_count > min_divisors {
            return n * (n + 1) / 2;
        }
        
        n += 1;
    }
}
```

## Complexity Analysis

### Time Complexity
- **Per number factorization:** O(√m) where m is the number being factored
- **For n-th triangle number:** Factor two numbers ~n, so O(√n)
- **To find answer:** Search ~12,000 values, so **O(k × √k) ≈ O(k^1.5)**

### Space Complexity
- **O(1)** - No arrays, only counters

### Actual Performance
- **~720 μs** for finding triangle number with > 500 divisors
- Very efficient compared to naive divisor counting!

## Mathematical Insights

### Triangle Number Formula
T(n) = 1 + 2 + 3 + ... + n = **n(n+1)/2**

Proof: Sum of arithmetic sequence with first term 1, last term n, n terms.

### Coprimality of Consecutive Numbers
**Theorem:** gcd(n, n+1) = 1 for all integers n

**Proof:** If d divides both n and n+1, then d divides (n+1) - n = 1, so d = 1.

### Divisor Counting Formula
**Fundamental Theorem of Arithmetic:** Every integer > 1 has unique prime factorization.

**Divisor formula:** Follows from choosing exponents independently for each prime.
